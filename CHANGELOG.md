# Changelog

История изменений TGMUOS. Даты — по сессиям разработки (октябрь 2026),
устройство — Anbernic RG35XX SP, muOS 2601.0, AArch64, glibc 2.38.

## 2026-10-27

### Fixed
- `src/telegram.c`: убрана повторная декларация `char message[TG_TEXT_LENGTH]`
  в ветке обработки TDLib-ошибок `handle_response()` — после правок сессии
  «Fixing Telegram Startup» переменная объявлялась трижды в одном блоке,
  и проект перестал собираться. Оставлено одно объявление с общим
  заполнением через `token_string()`.

## 2026-10-26 — сессия «Fixing Telegram Startup»

### Fixed
- TDLib на устройстве ожидала параметры внутри вложенного объекта
  `parameters` в `setTdlibParameters` — из-за этого запрос возвращал
  `400: Parameters aren't specified` и клиент не стартовал. Запрос
  исправлен, поведение проверено изолированным запуском на устройстве.
- Запросы к TDLib теперь коррелируются с ответами по `@extra`, ошибки
  показываются с именем метода запроса; добавлена обработка proxy-ответов
  `ok`.
- Долгий старт: синхронное обновление VLESS-подписки заменено на
  старт из валидного кэшированного профиля sing-box с фоновым
  обновлением подписки (`tools/run-client.sh`). Без валидного профиля
  старт требует успешного импорта подписки, прямого подключения нет.

### Added
- `tg_apply_subscription()`: переключение подписки и действие
  «Apply connection» применяют прокси TDLib в работающем приложении
  без перезапуска (изменение выбранного сервера сохраняется для
  следующего обновления профиля sing-box).
- Более скруглённые строки в Settings и списке чатов.

### Changed
- Обновлён бинарник и лаунчер на устройстве (с бэкапами); старый
  процесс оставлен работать — требуется один перезапуск клиента.

### Notes
- Начат скелет отдельного приложения **muVPN** (TUN-режим sing-box):
  UI, service-скрипт, package.sh, glyph, тесты. **Не упаковано и не
  установлено** на `/mnt/mmc/MUOS/application/muVPN`; финальный TUN-профиль
  ещё не перевалидирован на устройстве.

## 2026-10-26 — сессии «VLESS для muOS» / «Выбор VLESS-сервера»

### Added
- Импорт VLESS-подписки (`tools/import_vless_subscription.py`): ссылки
  TCP+TLS/Reality, генерация приватного sing-box профиля (SOCKS5 для TDLib).
- Экран выбора сервера: сортировка узлов подписки по TCP-latency,
  недоступные в конце; режим Automatic. sing-box v1.14.4 собран для
  AArch64 из официальных исходников (GPL-3.0, лицензия в `docs/licenses/`).
- Приватные данные подписки — только на устройстве (`/root/.config/tgmuos/`),
  в исходники и пакет не включаются.

## 2026-10-26 — сессия «Сборка TDLib для Anbernic»

### Added
- TDLib v1.8.0 собрана из официального исходника для AArch64
  (cross-build, OpenSSL/zlib статически; runtime-зависимости только
  glibc/libm, максимум `GLIBC_2.38`). Установлена как
  `lib/libtdjson.so` в проекте и на устройстве (SHA-256 совпал).
- Учётные данные Telegram (`telegram.conf`, `api_id`/`api_hash`) хранятся
  приватно (mode 600, исключён из git); на muOS лаунчер предпочитает
  `/root/.config/tgmuos/telegram.conf`.

### Verified
- `mtproto.conf` (публичные RSA-ключи Telegram) совпадает с ключами,
  встроенными в TDLib v1.8.0; приложение его отдельно не читает.

## 2026-10-26 — сессия «Обновление интерфейса и QR-вход»

### Added
- Собственный QR-кодировщик (`src/qr.c`, версия 5-L) для ссылок входа
  `tg://login?token=...` — без зависимости от libqrencode.
- QR-вход: `requestQrCodeAuthentication`, состояние
  `authorizationStateWaitOtherDeviceConfirmation` с выводом `link`.
- Скрытие экранной клавиатуры (X), прокрутка истории (D-pad/колёсико/
  page keys) с дозагрузкой старых сообщений, скруглённые сообщения,
  простые настройки (язык, анимации) с сохранением, русская локализация,
  русская/английская раскладки экранной клавиатуры.

## 2026-10-26 — сессия «Перевод на framebuffer renderer»

### Changed
- Рендеринг переведён с SDL video на прямой вывод в `/dev/fb0`
  (mmap; видимая область 640×480 32bpp, виртуальная высота 960).
  Причина: системный SDL muOS не имеет рабочего video-бэкенда
  (`fbcon` отсутствует, `offscreen` не запускается). SDL остался для
  ввода (GameController) и SDL_ttf.
- `src/renderer.c`, `src/ui.c`, экраны переписаны на `AppRenderer`;
  headless canvas для тестов; `--smoke-test`.
- Исправлены назначения кнопок и пути шрифтов (`res/fonts`, fallback
  `assets/fonts`).

## 2026-10-26 — исходное состояние

- Проект получен как статический макет: экран телефона переходил к
  жёстко заданным демо-чатам, реальной авторизации и отправки не было.
  Проанализированы примеры приложений muOS (Dolphin RT Stream,
  Bluetooth App, MuTube, Calculator).
