## Блокер #1 — TDLib

На устройстве TDLib v1.8.0 отвергается API Telegram:
`This TDLib version is incompatible; rebuild it for the current API`.

Сборка последнего TDLib master под AArch64 идёт через docker/qemu (fedora:39),
медленная (~50 мин), сбивается на `configure` zlib (тестовые бинари под qemu).
Использую схему: rpm aarch64 скачиваются на хосте, собираются в контейнере.

Файл скрипта: `/var/home/kyle/tgmuos-toolchain/build-tdlib-arm64.sh`.
Запечённые образы: `tgmuos-cross` (x86_64, сборка приложения), `tgmuos-arm64-build`
(последняя попытка таймаутнулась из-за dnf под qemu).
