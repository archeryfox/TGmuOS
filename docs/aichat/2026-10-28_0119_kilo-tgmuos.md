Консоль: `/mnt/mmc/MUOS/application/tgmuos/`, конфиги: `/root/.config/tgmuos/`.

## Сделано (commits 55e8e33 → 03ce355)

- QWERTY/йцукенгшщзхъ on-screen keyboard, мелкие клавиши букв
- Wrap сообщений в пузырях
- Статус-бар: время, батарея %, сеть, PROXY/НАПРЯМУЮ, VPN (pid-файл muVPN)
- MTProto-прокси из `/root/.config/tgmuos/mtproto.conf`
- Фото: downloadFile + LRU-кэш 12 слотов (dlopen SDL2_image)
- Папки чатов: вкладки «Все» + папки TDLib, Left/Right
- Кнопка «Выйти из аккаунта»: архивирует `data/tdlib` → `data/accounts/`,
  не уничтожает кэш (как NekoX/Nagram, tdlib/td#1197)
- Динамическая загрузка чатов: `updateNewChat`/`updateNewMessage` обновляют
  превью в реальном времени, `tg_poll` периодически запрашивает чаты раз в 3 с
- Загрузка чата при открытии: сначала `only_local: true` (быстро), потом
  полная — как у Telegram Desktop и forks
- **Авторизация/архив (03ce355):**
  - `update_chat` запрашивает фото чата через `downloadFile` и отслеживает
    `chat_lists` для определения архивных чатов (`chatListArchive`)
  - Архивные чаты скрыты из основного списка (`loadChats` использует
    `chatListMain`) и не кэшируются
  - `tg_open_archived_chat(chat_id)` загружает архивный чат по требованию
    с той же быстрой локальной+удалённой историей
  - Аватарка чата в списке (fallback — первая буква) и в шапке чата
  - Фото профиля обрабатывается через `updateUser`/`updateUserPhoto`
  - `updateFile` разрешает пути к фото чата и профиля
  - `tg_select_chat` вынесена в общий `tg_open_chat` хелпер
- Исправление `setTdlibParameters`: повторная попытка с legacy nested JSON
  schema при ошибке 400 "Parameters aren't specified" (Codex добавил логику,
  я проверил на устройстве)
