# TGMUOS — отчёт о проделанной работе (2026-10-28)

## Спринт: Telegram-клиент для Anbernic RG35XX SP (muOS)

### Цель
Создать функциональный Telegram-клиент для консоли Anbernic RG35XX SP под управлением muOS, с поддержкой TDLib, прокси (VLESS), чатов, медиа, профиля и динамических обновлений.

### Достигнуто

#### 1. Приложение запускается и работает
- `tgmuos` (225 KB) запускается на устройстве 192.168.0.151 (SSH root/root).
- Проходит `setTdlibParameters`, достигает `authorizationStateWaitPhoneNumber`.
- Чаты загружаются, описания групп приходят, профиль отображается.
- Кэш фото (24 слота), аватарки чатов, экран профиля (`screen_profile.c`) добавлены.

#### 2. Исправления багов
- `tg_stop()` — добавлен `destroy` для принудительного освобождения блокировки `td.binlog`.
- `telegram.conf` копируется на устройство (без него `api_id=0` передавался в TDLib).
- Спам `loadChats 404` — логируется один раз, флаг `chats_exhausted` сбрасывается при получении чатов.
- Навигация `BACKSPACE` в чате больше не ведёт на экран авторизации.
- Клавиатура в чате уменьшена (20px клавиши, один служебный ряд).

#### 3. Меню muOS
- Приложение отображается как **Telegram** с иконкой Telegram (`# GRID: Telegram`, `# ICON: telegram`).
- Папка переименована из `tgmuos` в `Telegram`.

#### 4. VLESS-подписка
- Подписка `https://hubcom.xyz/sub/26/ac24222e-1a88-466d-b9a7-fbbf5e87974b` импортирована: 14 узлов.
- Конфигурация в `/root/.config/tgmuos/sing-box.json`.
- `sing-box` для aarch64 собранный с тегами `with_utls with_gvisor` (71 MB).

#### 5. Инструменты
- **`anbernic-virtual-gamepad.py`** — виртуальный геймпад через `evemu-event`. Отправляет A, B, X, Y, Start, Menu, Select, L1, R1, Dpad. Работает на устройстве.
- **`Dockerfile`** — многоэтапная сборка (Fedora 39, кросс-компилятор aarch64, sysroot, smoke-test под qemu).
- **`.muxzip`** — готов: `/home/kyle/Projects/anbernics/tgmuos/tgmuos.muxzip` (23 MB).

#### 6. Happ TUN
- Happ (x86-64) запущен на хосте, TUN-интерфейс `tun0` активен.
- Прямое подключение через `tun0` к Telegram работает (`curl --interface tun0` = 200).
- SSH-туннель (SOCKS5) не работает — слушает только IPv6, на устройстве нет IPv6-маршрута.

### Проблемы

#### 1. sing-box не запускается на устройстве
- Причина: `uTLS is not included in this build` — бинарник не копируется корректно или старый процесс мешает.
- Порт 10808 не слушается.
- Устройство не имеет прямого доступа к Telegram (порт 443 заблокирован провайдером).

#### 2. muVPN не собирается
- В toolchain нет SDL2 библиотек (SDK/lib пуст).
- Восстановление sysroot из RPM неудачно (ошибки прав доступа).
- На устройстве нет gcc.

#### 3. Прямое подключение к Telegram заблокировано
- Провайдер блокирует порт 443.
- Happ TUN на хосте работает, но не может быть использован на устройстве без прокси.
